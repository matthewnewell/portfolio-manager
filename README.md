# Portfolio Manager

Every project in a business area, at once — The oversight view a business area lead uses to see all of their projects together.

**Status: placeholder.** Only a splash page exists so Conway's Depot's catalog can launch this
app (with the shared "← Conway's Depot" back bar). No backend yet; add one under `backend/` when
there's something to build, following the sibling apps' conventions.

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0    # :5190
```

Needs `~/conways-drawer` cloned alongside (see conways-depot's `scripts/clone-all.sh`).
